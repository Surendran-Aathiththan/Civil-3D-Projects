# Civil 3D Projects

Survey and infrastructure work in **Autodesk Civil 3D**.

## [Engineering Surveying – CE2150](Uni%20Project%20CE2150%20-%20Engineering%20surveying)

A University of Peradeniya engineering surveying project that turns field survey observations into a Civil 3D survey drawing.

| Stage | File |
|---|---|
| Raw field data from the total station | `22A2.SDR` |
| Processed point data | `My data.csv`, `My data.xlsx` |
| Civil 3D survey drawing | `Survey.dwg` |

**Skills:** importing survey data, managing points, and drafting surveys in Civil 3D.

## Opening the files

Open `Survey.dwg` in **Civil 3D** (AutoCAD can display the geometry). The point data opens in Excel.
